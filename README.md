A one-line resignation letter for The One-Line Exit on make.fun. The program writes the funniest single-line resignation letter it can into `entry.txt`, ready for the judge to compare two at a time.

> I resign: the coffee machine was the only colleague who never let me down, so I'm taking it with me to a better office.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```

The entry line is 119 characters long, and the output is deterministic: every run writes the exact same line to `entry.txt`.
